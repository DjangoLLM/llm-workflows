Who calls the tool?

The Model never calls tools. It reports the LLM's intent via ToolCallPart. pydantic_ai looks up the function in its registered tools and invokes it in-process.
① pydantic_ai.Agent → Model.request(messages, tools, output_schema)
▼
② PiWorkerModel → Temporal → TS piInference (LLM decides)
▼ returns {toolCalls:[{name,args}]}
③ PiWorkerModel → ModelResponse(parts=[ToolCallPart('echo', {…})])
▼
④ pydantic_ai.Agent looks up 'echo' in registered tools → calls Python function in-process
▼ returns dict
⑤ pydantic_ai wraps as ToolReturnPart → builds next ModelRequest → back to ①
