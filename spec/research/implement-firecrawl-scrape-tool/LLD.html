02
scrape_url phases
Phase · 01
Build request
URL = f"{_base_url}/v1/scrape". Headers: Authorization, Content-Type. Body dict: url = str(input.url), formats = fresh list(input.formats) (no aliasing).
Phase · 02
Issue HTTP
with httpx.Client(timeout=30.0) as c: then c.post(...). Wrap only the post call in try / except httpx.RequestError. Do not catch Exception.
Phase · 03
Validate envelope
Five ordered checks in §03 below. Each failure short-circuits via the error helper.
Phase · 04
Map & return
Assemble kwargs dict in HLD §5 order, then return ScrapeUrlOutput(**kwargs). Pydantic ValidationError propagates.

04
Mapping table & the format-key decision
Output fieldSourceRule
urlmetadata["url"]direct access
titlemetadata.get("title")nullable
markdowndata["markdown"] if requestedrequested but missing → raise

Decision
When a format is requested in input.formats but the matching key is absent in data, this story raises ToolExecutionError — it does not silently set the field to None. Rationale: "no silent coercion" rule from the HLD applies symmetrically to inputs, not just status codes. A provider that drops a requested format is a contract violation, not a soft success. Flag if this should be relaxed.
