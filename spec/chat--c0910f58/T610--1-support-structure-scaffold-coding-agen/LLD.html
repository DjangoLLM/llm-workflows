1 · What this subtask ships
T610 is the scaffolding pass — the seam and the supporting vocabulary that every driver and every caller will lean on. Drivers wire in later subtasks; this ticket guarantees the shape they snap into is stable.

A new sibling package, not a Django app. coding-agent-drivers lives next to freedom-agents under DjangoAgent/, with a src/coding_agents/ layout and its own pyproject.toml and tests/. Both freedom-agents and freedom-chat depend on it through [tool.uv.sources] path entries — no PyPI release.

The support structure is the deliverable. The genuinely-new code is the CodingAgent protocol, the run() / stream() adapters on the base wrapper, the typed error model, and the get_coding_agent() registry. Everything else is the monolith's logic relocated into one-concern modules.

Deferred wrappers ride along. gemini.py and claude.py ship inside the package (importable) but are not reachable through get_coding_agent() — they are present so registering them later is a one-line change.

★
Zero production importers — a pure lift behind a new seam.
Only the relocated test suite imported the old monolith. The move is mechanical; the CodingAgent seam, the typed errors and the registry are the only new surfaces, and each is covered by a unit test.

base.py — run() / stream() satisfy the protocoladded to BaseCLIWrapper
    async def run(self, prompt, policy=CODING_AGENT_POLICY) -> CLIResponse:
        return await self.execute(prompt, policy.output_format, policy=policy)

    async def stream(self, prompt, policy=CODING_AGENT_POLICY):
        queue = asyncio.Queue(); DONE = object()
        task = asyncio.ensure_future(
            self.execute(prompt, policy.output_format,
                         on_event=queue.put_nowait, policy=policy))
        task.add_done_callback(lambda _: queue.put_nowait(DONE))
        try:
            while True:
                ev = await queue.get()
                if ev is DONE: break
                yield ev
        finally:
            if not task.done(): task.cancel()
        self._last_response = await task   # re-raises timeout / launch errors
→
run() is a one-shot await → CLIResponse. stream() bridges the existing on_event callback into an async for via an asyncio.Queue; the final response (and any raised error) surfaces on self._last_response when the backing task is awaited. A caller that breaks early cancels the task in the finally. execute() itself is unchanged.

5 · NonInteractivePolicy
A frozen, CLI-agnostic dataclass: two knobs plus an escalation switch. Each driver's build_command maps it onto its own flags; a bare instance is the coding-agent contract.
policy.py@dataclass(frozen=True)
class NonInteractivePolicy:
    auto_approve:  bool         = True   # suppress approval dialogues
    allow_writes:  bool         = True   # edits + command exec permitted
    output_format: OutputFormat = OutputFormat.STREAM_JSON
    interactive:   bool         = False  # escalate to the native TUI

CODING_AGENT_POLICY = NonInteractivePolicy()                   # default contract
READ_ONLY_POLICY    = NonInteractivePolicy(allow_writes=False)  # review / plan
→
NonInteractivePolicy() → auto-approve, writes on, stream-json — the posture freedom-chat uses to drive a coding agent. allow_writes=False gives a non-mutating review run; interactive=True drops the non-interactive flags and hands the terminal to the CLI's native TUI.
6 · The registry seam
A name → factory map behind one function. An unknown name and a not-yet-registered driver take the same path — exactly what we want until a driver is wired.
registry.pyget_coding_agent
def get_coding_agent(name, *, working_dir, model=None) -> CodingAgent:
    try:
        factory = _REGISTRY[name]
    except KeyError:
        raise UnknownCodingAgent(name, known=sorted(_REGISTRY)) from None
    return factory(working_dir, model)
→
Each registered name maps to a small factory that constructs and configures its wrapper with working_dir + model. gemini / claude are absent from _REGISTRY, so get_coding_agent("gemini") raises UnknownCodingAgent("gemini", known=[...]) — the same path as a typo — until their subtask adds one line.
