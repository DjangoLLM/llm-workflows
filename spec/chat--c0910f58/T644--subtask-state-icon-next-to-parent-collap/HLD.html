High Level Design

Subtask State Icon in Task Tree

Add a one-character colored dot to existing subtask rows in the Plane task tree. The dot sits immediately to the right of the existing caret column and represents the subtask row's own workflow state.

Plane: CODIN-644 Phase: HLD Module: chat Surface: plane-tui web frontend

Scope

This is a small frontend-only addition to the existing React/Vite task tree in plane-tui. It does not add backend fields, rebuild the tree, change grouping, or introduce parent state rollups.

Primary Surface

  • web/frontend/src/components/tasks/TaskRow.tsx owns the row rendering change.
  • hooks/useTaskTree.ts already provides depth, hasChildren, and expansion state.
  • lib/types.ts already exposes TaskSummary.state with name, group, and color.
  • LifecycleBadge remains separate; it is for agent lifecycle, not workflow state.

Existing Behavior

  • Rows already have a caret slot for expanded, collapsed, or leaf state.
  • Depth indentation already comes from paddingLeft: depth * 2ch.
  • Top-level task state is communicated by section headers.
  • Subtasks already carry their own state data but do not render it inline.

Proposed Layout

Add a fixed one-character state-icon slot directly after the caret slot. Render the dot only for rows where depth > 0. Top-level rows stay visually unchanged.

State Color Contract

Prefer the authentic Plane color from task.state.color. If absent, fall back by task.state.group; unknown groups use the muted fallback.

Accessibility

  • The dot must expose the state name with title={task.state.name}.
  • It must also provide an accessible label equivalent to the state name, such as aria-label={task.state.name}.
  • Meaning cannot rely on color alone.

Test Plan

  • Top-level rows do not render a visible state dot.
  • Leaf subtasks render a dot while keeping the blank caret slot.
  • Expandable subtasks render both caret and dot.
  • The dot uses state.color when supplied.
  • Fallback color is used when state.color is absent.
  • The dot exposes the state name through title/accessibility labeling.

Out of Scope

  • Parent-row aggregate state indicators.
  • Any state indicator on top-level task rows.
  • Backend, API, or data-model changes.
  • Changes to agent lifecycle badges or running-agent counts.
  • Python/Textual TUI work.
